# Code of conduct

## The short version

Be decent. Assume the person on the other end is trying to get a patch to apply.

## What is expected

Technical disagreement is welcome. Take it to the evidence: run the patch, read the bytes, say what you measured. A reference patch from the program that defines a format settles more than an argument does.

Assume good faith about mistakes. A wrong offset or a wrong checksum is a thing to correct, not a thing to be scored against somebody.

## What is not

Personal attacks, harassment, or making somebody's identity the subject. Deliberate bad faith: reopening a settled question without new evidence.

## Scope

Issues, pull requests, discussions and commit messages on this repository.

## Enforcement

Report conduct privately through [GitHub's private vulnerability reporting](https://github.com/gufranco/anypatch/security/advisories/new), or publicly in the issue tracker when privacy is not needed. This is a small project with one maintainer, so the realistic response is that a comment gets removed or a person gets blocked.
