# Notice

anypatch is written from the specifications and open implementations below. They were read to learn each format; no code, text or test data was copied from them. Reference patches in the test suite were produced by running these programs on synthetic inputs.

|:--|:--|:--|:--|

| VCDIFF and xdelta3 secondary compression | [RFC 3284](https://www.rfc-editor.org/rfc/rfc3284), [xdelta3](https://github.com/jmacd/xdelta) by Joshua MacDonald | RFC; Apache-2.0 | Format and the DJW and FGK coders read; xdelta3 3.0.11 writes the reference vectors |
| IPS32 | The IPS32 parser in the Citron emulator | Not recorded; read only | Header and end marker read; nothing copied |

| BSDIFF40 | [bsdiff](https://www.daemonology.net/bsdiff/) by Colin Percival | BSD-2-Clause | Format read; bsdiff writes reference vectors |
| VCDIFF S version and code tables | [open-vcdiff](https://github.com/google/open-vcdiff) by Google; [igir](https://github.com/emmercm/igir) by Christian Emmer | Apache-2.0; GPL-3.0-or-later, read only | open-vcdiff's decoder read for the S version and its code-table layout, and its tool writes the S vectors and decodes the code-table checks; igir read for the RFC layout |

| NINJA 1 | Derrick Sobodash's NINJA 1.0 format specification and NINJA 1.01 PHP edition | Specification; GPL-2.0 source read only | Format written from the specification, with the source read for what it actually does; NINJA 1.01 runs as a separate program to exchange patches |
| DPS | The DPS page of the [UniPatcher wiki](https://github.com/btimofeev/UniPatcher/wiki/DPS), after Marc de Falco's DPS patcher, and UniPatcher's DPS reader | GPL-3.0 read only | Format read; no program that writes or reads DPS could be run to cross-check it |
| HDiffPatch | [HDiffPatch](https://github.com/sisong/HDiffPatch) by housisong | MIT | Format read from its patcher; its hdiffz writes the reference vectors in every codec and both layouts, and hdiffz and hpatchz exchange patches with anypatch |
| VPatch | [NSIS](https://github.com/kichik/nsis) VPatch by Koen van de Sande | zlib | Format read from its plugin's `apply_patch.c`; its GenPat writes the reference vectors in MD5 and CRC32 mode and with two entries, the sample patch NSIS ships is a vector, and GenPat and the plugin's patcher, built for POSIX, exchange patches with anypatch |
| JojoDiff | [JojoDiff](https://jojodiff.sourceforge.net/) by Joris Heirbaut | GPL-3.0 | Format learned by reading its patcher, `JPatcht.cpp`, without copying; its jdiff writes the reference vectors, and jdiff and jpatch exchange patches with anypatch |
| DLDI | [dlditool](https://github.com/blocksds/sdk/tree/master/tools/dlditool) by Michael Chisholm, in the BlocksDS SDK | GPL-2.0-or-later | Format learned by reading dlditool without copying; dlditool patches the generated reference cases, and its results are recorded as SHA-256 |
| xdelta 1.1 | [xdelta 1.1.4](https://git.tizen.org/cgit/platform/upstream/xdelta1/) by Josh MacDonald, in Tizen's port to glib 2 | GPL-2.0-or-later | Format learned by reading its patcher and EDSIO serializer without copying; its xdelta writes the reference vectors plain, gzip-compressed and unverified, and xdelta delta and xdelta patch exchange patches with anypatch |
| BSP | [bsp](https://github.com/aaaaaa123456789/bsp) by aaaaaa123456789 | Public domain | Format read from its specification and its patcher, `bsppatch.js`; its compiler, bspcomp, builds the reference programs, `bsppatch.js` produces their expected results, and it applies every boundary BSP anypatch writes |
